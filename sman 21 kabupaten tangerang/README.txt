WEBSITE PROFESIONAL SMAN 21 KABUPATEN TANGERANG

FILE:
- index.html : struktur dan konten halaman
- style.css  : desain, warna, layout, dan tampilan responsif
- script.js  : interaksi website
- README.txt : petunjuk

FITUR:
- Navigasi responsif untuk desktop dan ponsel
- Mode terang/gelap
- Pencarian berita dan filter kategori
- FAQ buka/tutup
- Formulir kontak dengan validasi front-end
- Tanggal dan tahun otomatis
- Tombol kembali ke atas
- Bagian profil, visi-misi, layanan, akademik, kegiatan, berita, agenda, PPDB, dan kontak

CARA MENJALANKAN:
1. Ekstrak ZIP.
2. Buka folder ini di Visual Studio Code.
3. Buka index.html dengan Live Server atau browser.

CATATAN:
Website ini adalah template profesional. Alamat, email, akun media sosial, berita, agenda, dan informasi PPDB perlu diisi dengan informasi resmi sekolah. Foto dan font eksternal memerlukan koneksi internet. Form kontak masih demo dan belum mengirim pesan ke server. Untuk penggunaan resmi, hubungkan form ke backend dan ganti foto ilustrasi dengan dokumentasi sekolah.
